## Lessons Learned

- Issue-less field start (#533) worked: gabby logged against the date with a `pending` marker and the dev host backfilled #309 cleanly at wrap-up. salmon never ran `/start-deployment` (logged under "ref TBD") — a reminder that every active field host should activate deployment mode so its log header carries the right issue ref from the start.
- Survey-pattern start points falling outside the local costmap is a plausible, concrete cause of "stops short → hover." Worth checking local_costmap bounds vs survey segment spacing before the next survey outing.
- Rain did not degrade OAK segmentation; calm mirror-water did. The perception robustness gap is glare/reflection, not precipitation.
- Runtime param changes during ops are not durable — gabby explicitly re-baked the endorsed ones into YAML. Good practice; keep doing it at session end.
