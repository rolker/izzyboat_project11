## Lessons Learned

- Issue-less field starts (#533) need the dev-host backfill run promptly — both
  per-host logs carried `Deployment issue: pending` until this wrap-up.
- The udp_bridge stale-packet gate shipped global default-ON; the field
  immediately found it over-broad (drops raw sonar / `/tf` / pointclouds). New
  latest-wins-style fixes should default to opt-in per topic, not global.
- `mru_transform` passes attitude through raw (no IMU→base_link URDF rotation),
  so a sensor mounting/alignment offset reaches the costmap directly — alignment
  must be correct at the driver/extrinsic level, not assumed handled downstream.
- The manda coverage planner works off live M3, but its tuning params aren't
  operator-exposed — a usability gap for survey planning.
