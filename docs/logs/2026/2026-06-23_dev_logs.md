### Lessons Learned

- No low-battery alarm fired before total shutdown. MAVROS battery config lacks low/critical voltage thresholds and pack capacity, so no SOC% and no alarm — and because the BMS cutoff is instantaneous, the alarm must be configured with margin above cutoff, not at it. Highest-priority fix before next outing.
- FCU dataflash logging is disabled on this boat (LOG_BACKEND_TYPE=0); reconstruct V/I history from the boat bag `/bizzy/mavros/battery`, not onboard FCU logs.
- `mission_plan` + `mission_manager/command` are now in the boat-side `logger` record list (`bizzyboat.yaml`, takes effect next rebuild+relaunch) — enables commanded-vs-actual trackline analysis next run.
- Issue-less field starts (#533) on gabby/salmon worked, but the same-site/same-symptom overlap with the prior day's #309 led salmon to a wrong issue-attribution conclusion. The dev session had already created #313 — propagation/visibility lag between dev-created issue and field hosts is the gap.
- salmon idea: oversized CAMP background GeoTIFFs (e.g. 28032×4480) load slowly; pre-downsample/retile for faster CAMP load.
