## Lessons Learned

- Operator-side Starlink subscription state (paused/active) is checkable before
  leaving the dock — candidate for the pre-deployment checklist.
- The udp_bridge return rate had to be raised to 1500000 "again" — the
  configured default keeps needing the same field override; make the durable
  setting explicit in the operator config (or solve via per-topic priority,
  udp_bridge#19 / transport rework udp_bridge#36).
- Rain drops are another environmental false-positive class for the
  segmentation-based collision avoidance (alongside whitecaps
  unh_marine_perception#31 and glint #42/#34); caused repeated manual takeovers.
- The issue-less field start + dev-side backfill flow
  (rolker/ros2_agent_workspace#533) worked: gabby logged with
