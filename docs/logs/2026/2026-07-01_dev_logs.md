## Lessons Learned

- **Live-ops logging gap**: telemetry/comms problems and Pilot contact marks lived only in
  the operator-logger rqt plugin (`~/data/logs/operator/<date>/`), not the markdown field
  logs. Wrap-up should always reconcile the operator-logger jsonl alongside the per-host
  markdown logs.
- **ZeroTier is unusable from the UNH/CCOM network** (UDP/9993 blocked + symmetric NAT →
  TCP-relay-only, no peer path to gitcloud). The reliable field-log/reconcile path is
  gitcloud's **AWS-public SSH alias `gitcloudap`**. Longer-term: request a UNH firewall
  exception for UDP/9993 or stand up a self-hosted ZeroTier moon.
- **Sterile-cockpit boundary**: a field agent produced a deep controller RCA during live
  ops that the operator never saw (busy flying the boat). Deep RCA belongs at wrap-up;
  in-field, log the symptom + mitigation and defer the analysis.
