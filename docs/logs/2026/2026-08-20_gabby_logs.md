**2026-08-20 11:23 -04:00** — COVARIANCE GAP CLOSED in `ais_contact_tracker` (commit afaa775, marine_ais). The tracker carried a literal `# todo, figure out covariances` and left BOTH the pose covariance and the twist covariance zero-filled on every contact — consumers got position and velocity with no way to weight either, and a zero on the diagonal asserts a perfectly known quantity. `fillCovariances` now maps the transmitted position-accuracy bit (ITU-R M.1371: high => better than 10 m) onto x/y variance, and marks quantities AIS never carries (altitude, roll, pitch) or that a given report omitted with a large finite 'unknown' stand-in rather than zero. **2026-08-20 11:23 -04:00** — IDENTITY-QUATERNION TRAP found by a failing test, worth recording because it is the kind of thing that reads as correct forever. The ROS default for `geometry_msgs/Quaternion` is the IDENTITY (w=1), not a zeroed quaternion. `ais_parser` only writes `pose.orientation` when the report carried a true heading (the decoder correctly nulls it at the AIS 511 'not available' sentinel), so an ABSENT heading was byte-identical to a REAL heading of due east — and no consumer could tell. MEASURED ON THE LIVE FEED: only 4 of 12 contacts report a true heading, so 8 would have been silently oriented east. Root-caused rather than worked around: `Navigation.msg` gains an explicit `heading_valid` flag set by `ais_parser`, which the tracker folds into the yaw covariance so downstream consumers (including the new layer) can distinguish the two. Additive field at the end of the message; nothing outside the marine_ais repo depends on it.

**2026-08-20 11:23 -04:00** — AIS COSTMAP LAYER IMPLEMENTED — new `ais_layer` package in the marine_ais repo (commit de4657f), siting the layer with its data source as `marine_radar_layer` and `s57_layer` do. Replicates CAMP's display-side interpolation, adapted for planning: each contact is dead-reckoned forward from its fix along COG at SOG and the swept region BETWEEN last-known and predicted position is painted, with an uncertainty envelope that grows with time since fix. Asymmetry is deliberate and documented in-code — over-painting costs a detour around empty water, under-painting costs a collision, so where the layer must guess it guesses wide. Gating: `navigational_status` blocks dead reckoning for moored/at-anchor/aground; expiry is per reporting class via `position_message_id`; a contact with no SOG/COG grows a reachable set at `unknown_speed` instead of being propagated; heading falls back COG-then-circle rather than fabricating an orientation; non-finite lat/lon/altitude are rejected before the ECEF conversion (the parser emits NaN for all three when a report omits them); previous-cycle bounds are re-requested so the master costmap clears where contacts have moved on. If the feed dies, contacts age out and the layer contributes nothing rather than stranding the planner.
