## Lessons Learned

- Issue-less field starts work, but backfill promptly: this deployment ran with `Deployment issue: pending` on both hosts; the #533 flow recovered it cleanly at wrap-up.
- Dev and field independently made the same chart_layer re-enable on the same day (#276 dev-side, gabby field-side) — the merge conflicted only in comments. Faster field→dev import cadence would have avoided the divergence.
- The boat cannot self-verify bridge transmission: `topic_statistics` covers only a subset of outbound topics (udp_bridge#17 comment), so receipt checks need the operator host.
- A site change invalidates more config than NTRIP: reference bathymetry store coverage, ENC coverage, and datum polygons all needed checking at Lewes. A pre-deployment "new site checklist" (NTRIP caster, ENC coverage, reference-store coverage, tide/current stations in deployment.yaml) would compress the first hour.
- FCU dataflash logging was disabled — when the strange noise / steering difficulty happened, the best PID desired-vs-actual source did not exist. Enable dataflash for future runs.
- Lifecycle-managed nodes are only recoverable if cleanup→configure round-trips; cube's redeclare bug (cube_bathymetry#114) turned a lifecycle recovery into a process kill.
